Or read the error like a professional

A #REF! error in a spreadsheet means a formula is pointing at a cell that no longer exists. In SSaI, this is usually because:

  • Someone renamed a tab.
  • Someone deleted a row.
  • Someone revoked sharing.
  • Someone moved the production data to final_FINAL_v9 without telling anyone.

If you have just produced a #REF! in your own sheet, do not panic. Press Ctrl+Z. If that doesn't work, check the version history. If that doesn't work, file an incident in _incidents. If you don't have an _incidents tab, create one. You are now mature.
